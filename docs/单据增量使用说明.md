# 单据增量（未闭环 SKU 新增单据）使用说明

> 页面位置：左侧导航 **单据增量**（在「批次对比」之后）
> 适用问题：「这次同步之后，哪些还没闭环的 SKU 又动了？动了哪张单、哪一步？」

---

## 一、这个页面解决什么

以前的「批次对比」是拿**两个批次**比 KPI。但现在的取数方式是
**钉钉每天导出最新全量、批次目录名固定**（`data\手机膜\手机膜\Part*_xx.xlsx` 反复覆盖），
批次表里**永远只有一个批次在长**，没有第二个批次可对比——只能看到「4027 个单据」这种总量，
推不出「谁动了」。

所以换一个维度：**盯住同一批「未闭环 SKU」身上的单据集合，看它今天比上一次同步多了什么。**
每次数据指纹变化（= 真的导入了新数据）系统自动拍一张快照，页面把相邻两张之间的差异摊开给你看。

> 「未闭环」= 复盘总览里 `valid=False` 的 SKU，和复盘页、预警页**同源**，不是另一套标准。

---

## 二、五个 KPI 分别是什么意思

| KPI | 含义 | 什么时候会涨 |
|---|---|---|
| **新增单据** | 未闭环 SKU 上**新出现**的单据（按 `SKU\|Part\|审批编号` 认定） | 业务新发起了一张审批单 |
| **单据新动作** | **本来就有**的单据上又推进了一步（审批动作 + 时间 + 操作人） | 老单被审批了下一步 |
| **状态变化** | 既有单据的审批状态变了（审批中 → 已结束 / 终止等） | 审批走完或被终止 |
| **新进入未闭环** | 新出现在「未闭环」集合里的 SKU | 新品立项 / 刚开始有数据 |
| **已闭环离开** | 该 SKU 已闭环，退出跟踪集合 | 流程走完，正常"毕业" |

> ⚠️ **新增单据的动作不重复计入「单据新动作」。** 否则「一张新单带 5 个节点」会被数成
> 1 张单据 + 5 个新动作，把指标灌水。要看新单有几个节点，看新增单据行的**节点数**列即可。

## 三、页面各区块怎么读

1. **增量走势图** —— 按日聚合的新增单据 / 新动作 / 状态变化。哪一天同步"有货"一眼看出；
   全 0 的日期说明那天没有新数据导入（不是系统坏了）。
2. **最近一次同步** —— 三个 Tab（新增单据 / 单据新动作 / 状态变化），**最新那一张快照的明细**。
   日常盯办主要看这里：刚刚那次同步到底进了什么。
3. **未闭环 SKU 增量排行** —— 按「新增单据 + 新动作」倒序。**谁在动、动了多少**排在最上面，
   带型号 / 开发类型 / 未闭环原因 / 当前单据数。**点某个 SKU 可只看它一个**。
4. **快照流水** —— 最近 30 次快照（新→旧），看「哪几次同步真的动了东西」。
   带 `基线` 标记的是首次建立，`疑似基线重算` 见第五节。
5. **导出 / 立即拍快照** —— 导出 xlsx（5 个 sheet，含口径说明）；「立即拍快照」用于手动打点。

## 四、什么时候会"没有数据"

| 现象 | 原因 | 处理 |
|---|---|---|
| 显示"尚无基线" | 该品类还没拍过第一张快照 | 正常，等下一次同步或点「立即拍快照」 |
| 拍了但没产生事件，提示「指纹未变化」 | 数据没变（自动管线一天跑 2 次，只有真导入才动） | 正常，不是故障 |
| 走势图全是 0 | 窗口内确实没有新数据 | 换个更长的天数看看 |
| KPI 全 0 但快照流水有记录 | 那几次同步的确没有增量 | 正常 |

> **首次拍快照只建基线、不产生事件**——否则一上来会把当时全部未闭环单据（实测 504 条）
> 都报成"新增"，那是噪声不是增量。

---

## 五、「疑似基线重算」标记

如果某次快照里**新增单据数超过当前单据总数的 60%**（且总数 ≥ 50），该次快照会打上
**疑似基线重算**标记。通常是这两种情况：

- 源单据换号段了（导出口径变了）；
- 基线文件被清过。

系统**只标记、不吞数据**——宁可让你看到"这轮 480 张单都算新增"并起疑，
也不会静默把增量丢掉。看到这个标记，建议先跟负责导出的同事确认口径。

## 六、和「趋势周报」「复盘总览」的分工

| 页面 | 回答的问题 | 时间尺度 |
|---|---|---|
| **单据增量** | 这两次同步之间，**谁动了**？ | 上一次同步 → 这一次（日级） |
| 趋势周报 | 最近 7 / 30 天**指标**怎么走的？ | 周 / 月 |
| 复盘总览 | 当前未闭环的 SKU **卡在哪一段**？ | 横截面（现在） |
| 预警 / 联动提醒 | 现在**该催谁**？ | 横截面 + 按人 |

一句话：**增量页回答"动没动 / 谁动的"，复盘与预警回答"卡在哪 / 该催谁"。**

## 七、常见问题

**Q：为什么只统计未闭环 SKU，已闭环的不管了？**
A：已闭环的 SKU 不会再推进，留在跟踪集合里只会让数据无谓变大。而且未闭环才是需要盯办的对象。

**Q：单据是按什么认定的？会不会重导之后全变"新单据"？**
A：按 `SKU + Part + 审批编号`（编号缺失时用创建时间兜底）。**刻意不用数据库自增 ID**——
重导会整批删掉重建，自增 ID 每次都变，用它会变成"每张单都是新的"。

**Q：一天提示两次"已记录增量"会有重复吗？**
A：不会。指纹（审批状态 + 节点动作列表）没变就直接跳过，只有真导入才产生事件。

**Q：历史能追多久？**
A：事件保留 **400 天**、最多 **2000 条**（都保留最新的），足够排障与看趋势。

**Q：手机壳的数据为什么少/有「目标待校准」提示？**
A：手机壳的评级线目前继承手机膜（待业务校准），与增量本身无关；增量页的口径与复盘一致。
