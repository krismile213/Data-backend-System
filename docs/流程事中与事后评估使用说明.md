# 流程事中与事后评估 使用说明

> 面向：流程管理员 / 日常催办人。
> **事中页回答「现在卡在哪、该催谁」；事后页回答「已经发生了什么、亏了多少」。**
> 两页是同一份数据（钉钉审批导出 → ETL 入库）的两个视角，不是两套数。

---

## 一、两个页面在哪、什么时候用

| 页面 | 侧栏入口 | 回答的问题 | 数据更新节奏 |
| --- | --- | --- | --- |
| 事中日报 | 事中日报 | 现在哪个 SKU 卡在哪一段、卡了多久、该找谁 | 每天 **09:20 / 14:50** 自动管线跑完即可看 |
| 事后评估 | 事后评估 | 已闭环 SKU 的时效 / 销量 / 金额三指标 | 每次打开**实时计算** |

配套的两条自动化链路（无需人工触发）：

1. **上游同步**：计划任务 `DingTalkApprovalSync` 每天 09:00 / 14:30 拉钉钉审批导出（约 7.5 分钟）。
2. **下游管线**：计划任务 `DataAdmin-AutoPipeline` 每天 09:20 / 14:50 增量导入 → 复盘重算 → KPI 快照 → 生成当日日报。

> ⚠️ 下游必须晚于上游跑完。若改动钉钉同步时间，**必须同步改** `scripts/install_auto_etl.ps1` 并重新注册，否则管线会读到「写了一半」的 xlsx。

## 二、事中日报页怎么读

### 2.1 顶部四个 KPI

| 指标 | 含义 |
| --- | --- |
| 在研 SKU | 任一 Part 仍处于「审批中」的 SKU 数 |
| 超期 SKU | **任一段**已超过该段目标天的 SKU 数（最坏的那个决定） |
| 临近预警 | 已用 ≥ **目标 × 85%** 目标天的段数 |
| 多轮提交 | 同一 Part 单据被撤回重提的 SKU 数 |

### 2.2 段状态机（唯一判据，别凭感觉）

对每一段（起点节点 → 终点节点）判定：

| 状态 | 判据 | 处理 |
| --- | --- | --- |
| 未开始 | 起点节点无时间 | 等前序，不用管 |
| 进行中 | `已进行 ≤ 目标 × 85%` | 正常推进 |
| 预警 | `已进行 > 目标 × 85%` 且 `≤ 目标` | **提前干预**，此时还来得及 |
| 超期 | `已进行 > 目标` | 需要上报 / 跟进 |
| 已完成 | 终点节点已有时间 | 不进预警区（不误报已完成段） |
| 留空 | 该段是部门间留空段 | 不计考核 |

- `已进行 = 今天 − 起点时间`；`超期天数 = 已进行 − 目标天`（只对超期段有值）。
- **判据是 `>` 不是 `≥`**：刚好等于目标天仍算预警，不算超期。
- 85% 系数可在 **时效规则配置 → 事中预警系数** 调整（默认 0.85）。

### 2.3 三张表

1. **风险预警区**：`当日新超期`（今天刚越过目标线 → **今天就要上报**）、`持续超期`（此前已超期 → 跟进）。
2. **临近超期预警**：达到目标天 85% 的段 → 这是事中干预价值最高的一栏。
3. **在研清单**：每个在研 SKU 一行（最差段 / 部门 / 超天数 / 预警段 / 状态 / 多轮 / 负责人）。

任意一行都可点开看**事中档案**：型号与状态、多轮提交警示、核心原因（因果链）、段级时间轴（部门 / 环节 / 状态 / 已进行 / 目标 / 预警线 / 负责人）。

### 2.4 日报 xlsx（按钮「生成今日日报」）

- **落盘**：`<数据根>\<最新批次>\reports\事中日报_YYYYMMDD.xlsx`（同日重跑**覆盖**）。
- **保留**：按 `时效规则配置 → 日报保留天数`（默认 90 天）自动清理。
- **sheet**：基础 5 张，有豁免 SKU 时追加第 6 张「豁免备查」。

| sheet | 内容 |
| --- | --- |
| 在研SKU状态总表 | 每 SKU 的状态 / 当前停留环节 / 已停留·目标·距超时 / 预警段数 / 多轮提交 / 核心原因 / 责任人 / **人工登记** |
| 超期明细 | 进行中超期段（终点未完成且 `已进行 > 目标`） |
| 风险预警 | 即将超期（越过 85% 线但未到目标） |
| 在研SKU甘特图 | 每在研 SKU 一块的分段条形（未完成段延伸至今日） |
| 异常上报清单 | 当日新超期 + 持续超期累计（拿去上报的那张） |
| 豁免备查* | 被移出追踪的 SKU 及原因（人工登记/换号/末端终止/运输闭环） |

> \* 无豁免时不生成该 sheet，不产生空页。
> 首日运行没有上一份快照时，甘特图对比基线缺失属正常——是还没有基线。

**「人工登记」列（2026-10-15 新增）**：跟着日期走的在研备注（如「暂时不弄了」「苹果18duo，23号发售」）。
真源是**生成器之外**的持久文件 `资产文件\事中日报人工登记.xlsx`（子表 `人工登记`，列 `SKU｜备注｜更新日期`）——
因为日报每天整体重新生成、幂等覆盖，**手填在表里的备注下场生成就被冲掉**。改备注只改那个文件，
次次生成自动带到新日报；同一 SKU 多行以最后一行为准。

> ⚠️ 与「豁免备查」里的**人工登记（免催办）**是两件事：那个在
> `资产文件\SKU登记表.xlsx` 的同名子表，作用是把 SKU **移出追踪**。本列只影响展示，
> 不影响任何时效/预警/豁免判定——所以故意分成两个文件，防止误填把 SKU 踢出追踪。

## 三、事后评估页怎么读

只统计**三部门全完成**的 SKU（`可评估 SKU`），口径固定为：

1. **时钟起点** = 品类规则集的 `startNode`（手机膜 = **取数**；手机壳 = **提案**）。
2. **终点** = 最晚**空运**货件到货时间（空运到了就能开卖）。
3. **推迟天数** = `起点 → 最晚空运到货 − 60 天底线`（60 = 空运底线，对齐路线总评级）。
4. **亏损** = `推迟天数 × 评级日均区间 × 单价`；**增益仅在提前完成时才算**。

表格列：SKU / 评级 / 方向（亏损·增益·持平）/ 起点日 / 跨度 / 底线 / 推迟 / 少卖件数 / 损益金额 / 备注。

- **金额是区间估计，不是精确值**（日均来自评级档区间）。
- `备注` 栏会写出口径降级，例如：`无空运货件·按运营路线降级`、`评级未命中`、`缺单价`。
- 按钮「导出三指标 xlsx」导出**时效 / 销量 / 金额**三个 sheet。

## 四、读之前先知道的几件事（口径与坑）

1. **多轮提交**：同一 SKU 同一 Part 有多张单据时，按**最早一轮**取值；若后续还有更新的轮次，标注为「多轮提交·疑似漏报」，**不静默合并**。
2. **反向段**：段耗时为负不是错，常见于「先线下做、后补录」；后台对手机壳把负值标成 `—补录(N天)` 而不报「⚠反向」。
3. **手机壳的目标天 / 评级线目前是"继承手机膜的名义值"**（顶栏品类选择器会亮出「待校准」标记）。因此手机壳的任何「目标 / 超期 / 预警 / 评级」判定**只能当预警参考，不能当既定 KPI**。业务确认数值后才算校准。
4. **已完成的段不进预警区**，所以「预警段数」为 0 不等于这段没风险，只说明当前没有未完成的段。
5. **数据源优先级**：系统业务时间列 > audit 上报 > 审批动作时间。三者在个别 SKU 上会不同，排障时以系统列为准。
6. **部门边界口径（2026-09-24）**：产品部终节点 = **素材交付**（=Part6「产品营销素材加工」，审批记录 audit 时间；该节点无系统业务时间列）；**运营段起点同 = 素材交付**，终点 = max(上架, 广告设置)。产品段目标 23/38 与运营段 7 未变。

## 五、离线对照（同一口径的另一条腿）

仓库 `流程复盘/route_check_sys.py` 是**系统口径**的离线实现，与后台同源同义：

- 产出 `output/route_路线复盘_系统口径.xlsx`，第 2 张 sheet **「事中盯办」** = 事中页的离线版本（每 SKU 只列**当前卡点段** + 状态 + 催办动作，按卡住天数降序，可直接照着打电话）；
- 默认只列「当前卡点段」；`--inflight-all-segs` 放开全部段，`--no-inflight` 关闭；
- 核对脚本 `流程复盘/check_inflight.py`（读产物做列/枚举/自洽/快照幂等/零波动核对）。

> 后台用于**日常盯办与上报**；离线脚本用于**留档、对比与排障**。两边报的是同一套数。

## 六、常见问题

**Q：页面显示「无在研 SKU」？**
A：说明当前品类的单据都已完成/终止。先确认顶栏**品类**与**批次**选对了。

**Q：KPI 与昨天不一样，是不是数据坏了？**
A：先看是否跨天（「已进行天数」本身按天增长，跨天变化是正常的），再看上游同步是否成功（`backend/state/auto_pipeline.log`）。

**Q：改了规则没生效？**
A：规则保存后会说「已按新规则重新计算」。若计划任务时间类需求，**规则页改不了**——那属于 Windows 计划任务，见 §一。
